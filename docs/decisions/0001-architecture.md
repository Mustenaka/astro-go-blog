# 0001 架构基线

日期：2026-09-08。状态：已采纳。

1. **内容在 Git。** 文章、作品、页面都是 `content/` 下的 MDX/YAML，schema 在构建期校验。理由：可审阅、可回滚、可被 AI 直接读写，且不依赖任何运行中的服务。
2. **后端不存文章。** Go 服务只管认证、资产签发、计数、构建触发与 MCP；改内容的唯一方式是写 `content/` 文件。理由：2026 年 7 月旧站入侵的根因是面向公网的动态渲染与数据库，公开站必须是纯静态文件。
3. **资产走 `/assets/` 约定。** 内容里只写 `/assets/<key>`，构建期由 rehype 插件改写为 `PUBLIC_ASSET_BASE`。理由：大文件不进 Git 也不占服务器磁盘，切换 CDN 只需改一个环境变量。
